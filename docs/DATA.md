# 数据格式

[返回首页](../README.md)

## 比赛

```json
{
  "id": "my-match-001",
  "title": "2v2个人竞速",
  "subtitle": "我的赛事 · 两局战报",
  "date": "2026-10-30",
  "teams": [
    {"name": "左队", "logo": "../../assets/logos/bomiao-logo.png", "players": [
      {"name": "选手甲", "scores": [11, 8]},
      {"name": "选手乙", "scores": [7, 9]}
    ]},
    {"name": "右队", "logo": "../../assets/logos/handao-logo.png", "players": [
      {"name": "选手丙", "scores": [9, 11]},
      {"name": "选手丁", "scores": [6, 7]}
    ]}
  ],
  "rounds": ["11城", "亚特兰蒂斯"]
}
```

此示例可存为`examples/matches/我的比赛.json`。队标路径基于配置文件所在文件夹；`total`可放在个人或队伍层级，提供时会进行求和校验。

| 字段 | 用途 |
|---|---|
| `id` | 累计统计的唯一比赛ID。批量CLI在未提供时使用文件名；重复ID会报错。 |
| `title` / `subtitle` | 海报标题和右上角说明。 |
| `teams` | 左队、右队，各两名选手，顺序决定画面位置。 |
| `scores` | 逐局有限数字，与地图数量一致；空白、null和数字字符串不接受。 |
| `rounds` | 地图全名或索引别名；重复赛道保留。 |
| `first_places` | 可选，个人逐局布尔数组，指定实际第一名。 |
| `show_stars` | 是否显示赛道星级，默认显示。 |

调整一局背景裁切：

```json
{"map": "心渊", "background_position": "67% 50%"}
```

排名统计默认根据每局最高正分计第一，同最高分按并列第一；四人均为0则无人计第一。有额外同秒规则时，给相关选手填写`first_places`，长度与`scores`相同。

## 名字合并

`--aliases`接收“战报名→榜单名”的JSON对象。映射只进行一层，避免隐式猜测姓名。例如：

```json
{"沐瑞": "林敏波", "喵帕斯": "牢喵", "大🦐": "乐乐", "泪": "路障", "岛": "小岛"}
```

同场两个人若映射到同一名字，会报错。新增选手时核对显示名与真实身份，别用“总分刚好相等”作为唯一识别依据。

## 均分榜输入

```json
{
  "event": "我的赛事",
  "updated": "2026-10-30",
  "rows": [
    {"name": "选手甲", "total": 19, "games": 2, "average": 9.5, "rate": 50, "first_place_count": 1}
  ],
  "pending": ["暂无成绩的选手"],
  "overall": "9.50"
}
```

`rate`使用百分数单位，`50`代表50%；`overall`是可选总均分校验值。排名由渲染器按均分重排，同均分使用`1、2、2、4`形式并列。

建议用`standings`命令生成这份数据，而不是手工累加四舍五入后的平均值。`standings`会保留`applied_matches`，输入所有原始比赛即可重复生成一致结果。

## 输出与边界

- 战报支持1–12局，均分榜支持1–12名已参赛选手。
- 输出目录会自动创建，已有同名图片会追加版本号。
- 战报校验结果为工作目录下`validation.json`；均分榜为输出目录下`ranking-validation.json`。
- 比分JSON是本地可信输入；本项目是CLI渲染工具，不是接收任意外部文件的在线上传服务。
- 不同操作系统的系统字体可能不同；需要固定视觉效果时使用同一有权使用的字体文件。
